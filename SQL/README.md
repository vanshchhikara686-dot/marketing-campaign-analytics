# Marketing Campaign Performance & ROI Analysis

An end-to-end data analytics project focused on evaluating digital marketing campaign performance, measuring return on investment (ROI), and identifying opportunities to improve marketing efficiency.

## Project Overview

This project analyses marketing campaign data to understand how different advertising channels and campaign types contribute to business performance.

The analysis uses Excel, SQL Server, and Power BI to transform raw marketing data into actionable business insights.

## Tools & Technologies

* **Microsoft Excel:** Data cleaning, transformation, pivot tables, and exploratory analysis.
* **SQL Server:** Data querying, aggregation, and performance analysis.
* **Power BI:** Interactive dashboards, KPI reporting, and data visualization.

## Dataset Description

The dataset contains marketing campaign performance records with the following fields:

* Month
* Campaign ID
* Channel
* Campaign Type
* Campaign Name
* Spend (INR)
* Impressions
* Clicks
* Conversions
* Attributed Revenue (INR)

## Key Business Questions

1. Which marketing channels generate the highest revenue?
2. Which campaigns deliver the best return on ad spend (ROAS)?
3. How efficiently is marketing expenditure being converted into revenue?
4. Which campaign types generate the strongest results?
5. How does campaign performance change over time?
6. Which channels offer opportunities for better budget allocation?
